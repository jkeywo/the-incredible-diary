# Lora

Bundled unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/lora), downloaded 30 September 2026.

`Lora-Variable.ttf` is the upstream `Lora[wght].ttf` file. Diary button labels use weight 600. The font is distributed with the game for consistent Windows and web rendering.
